# Проверка водоснабжения в развертках

Из корня репозитория запустите `python3 -m http.server 8765`, затем откройте:

- http://localhost:8765/tests/elevation_water.html
- http://localhost:8765/tests/elevation_water.html?narrow=1 — панель при ширине 480 px.

Ожидаемый итог: **ALL TESTS PASSED**. Проверки используют настоящий движок планировщика и события его интерфейса: создание выводов, все три вида труб, вертикальные участки и длины, перетаскивание, штатное меню ПКМ и разделение трубы, подключения котла, сериализацию и восстановление, переключение слоев. Сохранение синтетических изменений в проект отключено внутри тестового iframe. Перезагрузка страницы начинает проверку заново.

Для ручной проверки: открыть комнату в «Развертках стен», выбрать «Водоснабжение», затем инструмент трубы. Щелчки строят маршрут; щелчок по цветному выводу подключает его к маршруту. Escape/ПКМ по свободной части стены завершает построение. В режиме выбора перетаскиваются узлы и участки с незакрепленными концами; ПКМ по трубе или узлу открывает штатные действия. Проверить также серые неактивные розетки, иконки отделки и доступность закрытия развертки.

Высота и привязка узла хранятся в `Pipe.vertexes[].water_elevation`; `point` остается координатой плана. Старые проекты без этих данных отображают узлы труб на уровне пола, а высоты выводов берутся из существующих свойств приборов. Газовый котел сохраняет идентификатор `gas_boiler`, поэтому прежние проекты и газовые подключения совместимы.
